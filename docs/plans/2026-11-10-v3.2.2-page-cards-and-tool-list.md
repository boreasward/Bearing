# v3.2.2：「今日」「账户」的卡片化与工具面板 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 v3.2.2：「今日」页把简报按小节拆成卡片（左文字、右账户与行情），「账户」页五张卡，右侧抽屉加只读的「工具」面板。不加业务能力、不加迁移、不加新接口。

**Tech Stack:** Python 3.11 / FastAPI / psycopg；Svelte 5（runes）+ bits-ui + Tailwind 4.3（容器查询用内建的 `@container` 与 `@[Npx]:` 变体）；pytest、vitest + @testing-library/svelte。不新增任何依赖。

**Spec:** `docs/specs/2026-11-10-v3.2.2-page-cards-and-tool-list-design.md`（下文「spec §x」）。

## Review Focus

1. 简报正文里出现以 `## ` 开头但不是已知标题的行，或同一个已知标题出现第二次（agent 写的文字里可能有）：不切成新小节、不丢内容、`key` 不重复 → Task 1 `tests/test_v3_brief.py::test_split_brief_ignores_unknown_and_repeated_headings`。
2. 简报没有页脚、只有标题、空串、行尾带 `\r`：`split_brief` 不抛，`footer` 为 `None`，最后一段留在它所在的位置 → Task 1 `tests/test_v3_brief.py::test_split_brief_without_footer_or_body`。
3. 简报的 `run_id` 为空、指向不存在的运行、或运行的 `market` 是 `{}`：接口仍 200，`market` 为 `null` → Task 1 `tests/test_api_briefs.py::test_brief_market_is_null_without_run_or_snapshot`。
4. 深链打开历史简报而简报列表还没到或取失败：不能把历史简报当成最新（否则历史日期下出现可点的「记成交」）→ Task 2 `TodayView.test.ts` 的 `a deep-linked session is historical until the list proves it is the newest`。
5. 前端已重建而页面服务还没重载（接口没有 `sections`）：页面把整篇 markdown 放进一张「简报」卡，不是空白 → Task 2 `TodayView.test.ts` 的 `falls back to one card when the server sends no sections`。

## 接口契约（Task 1 产出，Task 2 消费）

`GET /api/briefs/latest`、`GET /api/briefs/{session}` 在现有字段之外：

```json
{
  "sections": [{ "key": "changes", "title": "和昨天比变了什么", "markdown": "- 新计划 FER：…" }],
  "lead": null,
  "footer": "数据截至 2026-11-09 收盘（…）。规则未经验证，不构成投资建议。…",

              "breadth": {}, "spy_ret20": -0.033, "etf_table": [], "macro": {} }
}
```

`sections` 按简报里的顺序，`markdown` 不含 `##` 标题行；`market` 没有 `watch` 键，取不到时为 `null`。
