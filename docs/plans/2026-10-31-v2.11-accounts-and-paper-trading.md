# v2.11.0 账户与模拟交易 Implementation Plan

> **For agentic workers:** 按 Task 顺序执行；每个 Task 的步骤用 checkbox（`- [ ]`）跟踪。实现子代理用别名 `sonnet`，审查用 `opus`（项目 `CLAUDE.md`）。**本 plan 待用户确认后才开始执行**（spec §17 的 Q1–Q11 已于 2026-10-31 按默认确认，见 spec §20）。REQUIRED SUB-SKILL：`superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`。

**Goal:** 真实账户与模拟账户同一套账本（`account-1`：初始现金、成交、出入金、每日权益、对账）；两个模拟账户——Agent 自管（`agent-portfolio-1`，每天看着自己的持仓、现金与当天的 Agent 计划下单，宿主校验、次日按 `paper-fill-1` 成交）与照计划机械执行（`follow-plans-1`）；`daily` 图新节点 `accounts`（`stages-5`、`daily-2`）；新顶级菜单「账户」（概览 / 持仓 / 成交 / Agent 决策 / 对比）；月度收益率 `monthly-5`。迁移 030。

**Architecture:** 纯函数层新增 `workbench/accounts.py`（账本口径）、`workbench/paper_fill.py`（模拟成交与宿主退出，复用从 `plan_shadow.py` 抽出的逐日步进）、`workbench/paper_strategies.py`（可买集合、上限股数、照计划执行、订单校验）、`workbench/agent/portfolio_check.py`（证据块与输出校验），扩展 `monthly.py`、`stages.py`、`agent/graph.py`；编排层新建 `workbench/paper_accounts.py`（`accounts` 节点的四步与账户用例）与 `workbench/account_views.py`（读视图），`service.py` 只加节点入口与建议股数的权益来源，`workflow.py` 升 `daily-2`；仓储层 `repository.py` 的成交 / 快照 / 出入金 / 持仓状态读写全部带 `account_id`（缺省真实账户）；API 新建 `api/routes/accounts.py`；前端新路由 `account` 与 `routes/Account.svelte`，复盘页搬走两个页签。

**Tech Stack:** Python 3.11 / FastAPI / psycopg 3 / PostgreSQL；LangGraph（`daily` 图加一个节点）；Svelte 5 + Tailwind v4 + `lib/ui/` 原语；Vitest；pytest（离线，SQL 测试用一次性库）。无新依赖。

**Spec:** [docs/specs/2026-10-31-v2.11-accounts-and-paper-trading-design.md](../specs/2026-10-31-v2.11-accounts-and-paper-trading-design.md)

## Review Focus

1. **模拟成交混进真实口径**：任何读成交的调用方在没传 `account_id` 时拿到模拟账户的行，链状态、纪律、复盘卡、持仓状态因此改变。→ Task 1 `test_list_trades_defaults_to_real_account`、`test_trade_readers_all_scoped`（静态扫描 `repository` 里每个 `FROM trades` 都带 `account_id`）；Task 3 `test_paper_fill_does_not_change_chain_state`。
2. **一天两次**：同 session 重跑或续跑再调一次模型、再挂一遍单、再写一行权益。→ Task 3 `test_accounts_node_rerun_same_session_is_noop`、`test_resume_from_accounts_reuses_decision`。
3. **影子与账户不一致**：同一份计划、同一组日线，`paper-fill-1` 与 `plan-shadow-2` 给出不同的入场 / 退出日或价。→ Task 2 `test_paper_fill_matches_shadow_v2`（参数化三类型 × 三情形 × 止损 / T1 / 时间止损）、`test_shadow_v2_unchanged_after_refactor`（重构前后结果逐字相同）。
4. **重复买同一条链**：作废后次日重挂、止损出局后再进、`next_open` 过了首日仍挂。→ Task 2 `test_buyable_excludes_consumed_chain`、`test_next_open_only_on_valid_from`、`test_follow_plans_does_not_replace_voided`；Task 3 `test_settlement_marks_chain_done`。
5. **真实账户数字对不上**：补录昨天的成交后权益行没更新；开账持仓扣了现金；出入金算进模拟账户。→ Task 2 `test_opening_position_does_not_reduce_cash`；Task 3 `test_real_equity_recomputed_after_backfill`、`test_flows_rejected_for_paper_account`。
6. **漏跑的日子**：周一没跑，周二运行只结算周二，周一触及的止损被跳过。→ Task 3 `test_settlement_loops_missed_sessions`。
