# v3.2.0：检验与复盘、研究与跟踪、页面的时间控件与金额 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 v3.2.0：每份已结束计划的执行复盘（偏差标签、R、假设结果）、带样本门槛的规则检验与周报；用户在对话里发起、宿主每天盯条件、agent 到点复看的研究记录，研究转成的计划不占名额；页面的日期 / 时间控件与两位小数带 `$` 的金额。

**Architecture:** 沿用 v3.1 的分层。**纯函数**新增 `execution/retrospect.py`（复盘行、偏差标签、假设结果、周汇总、规则分组）与 `execution/research.py`（研究条件的校验、文案、判定）；**编排层**新增 `facts/research_review.py`（每日研究复查，与 `facts/review.py` 同一做法）、`facts/retrospect.py`（从库里组装复盘视图）、`facts/research_repo.py`（研究两张表的 SQL）；工具面加 4 个研究工具到 35 个，`save_plan` / `revise_plan` / `agenda` 按「研究计划不占名额」改；每日任务第 3 步加研究复查、周末交易日加周报；页面接口加研究与复盘两组路由；前端加「研究」「复盘」两块并改三个表单与金额显示。数据改动在迁移 035：`v3_research`、`v3_research_events`、`v3_plans.research_id`、`v3_briefs.weekly_md` / `pushed_weekly_at`。

**Tech Stack:** Python 3.11 / FastAPI / psycopg / PostgreSQL；Svelte 5 + bits-ui + Tailwind 4（`web/src/lib/ui` 现有组件层）；pytest（离线 + 一次性库 55433）、vitest。不新增 Python 依赖、不新增前端依赖（日期 / 时间用原生 `<input type="date|time">`，经现有 `Input` 组件的 `type` prop）。

**Spec:** `docs/specs/2026-11-08-v3.2-retrospect-research-and-page-polish-design.md`（下文「spec §x」），它在 `docs/specs/2026-11-06-v3.1-plan-line-account-and-web-design.md`（下文「v3.1 §x」）之上；两者冲突以 spec 为准（spec §15）。

  - 研究结论三个：`ready`（可以出计划）/ `watch`（值得盯）/ `reject`（否决）。
  - 研究条件四种：`close_above`（收盘站上 {level}）/ `close_below`（收盘跌破 {level}）/ `touch_below`（最低价触及 {level} 或以下）/ `close_above_ma`（收盘站上 {ma} 日均线，`ma` ∈ 20 / 50 / 200）。
  - 研究事件七个：`created`、`concluded`、`triggered`、`planned`、`rejected`、`expired`、`dropped`。
  - 入场类型四个：`zone_limit`、`breakout_stop`、`next_open`、`pullback`（回调买入）。
  - 偏差标签代码与文案：`not_bought_in_zone`「未买入：价格进过入场区间」、`not_filled`「未买入：价格未进入场区间」（不算偏差）、`entry_out_of_zone`「买价出区间」、`over_bought`「多买」、`stop_order_missing`「止损未挂」、`late_sell_after_stop`「止损触及后晚卖 {N} 个交易日」、`late_sell_after_instruction`「卖出指令后晚卖 {N} 个交易日」、`early_sell`「早卖」；无偏差标签记「照做」。
  - 假设结果状态三个：`not_filled`（未成交，原因 `close_below_stop` / `never_in_zone`）/ `exited`（已离场）/ `unfinished`（进行中）。
  - 配置默认：`research_sessions = 20`（范围 [1, 60]）、`research_entry_atr = 4.0`（范围 [2, 8]）、`retro_min_sample = 10`（范围 [1, 100]）。
  - 面向用户的固定文案：「样本不足」「条件已到，待复看」「观察中」「尚无条件」「缺日线，未复查」「日线不足，未检查」「{n} 个交易日条件未到」「研究中」「照做」「补录，不计」「进行中」「还没有已结束的计划」「金额单位美元」「研究 {股票} 尚无条件」「研究复看 {股票}」「规则未经验证；样本不足的组不给数」。
  - 价格与金额：`price_value` 取到分（`40.5 → 40.50`、`98.000000 → 98.00`、`123.4567 → 123.46`，`ROUND_HALF_UP`）；页面金额与价格两位小数、前缀 `$`、负数 `-$12.34`。
- **时间口径**：交易日用纽约日历（`data/calendar`）；记成交的日期 / 时间控件按美东（`America/New_York`）拼成带偏移的 ISO；简报与页面显示用北京时间（`fmtBeijing`）。

1. 延续过的待入场计划（`continue_plan` 覆盖了 `valid_from`）过期：偏差标签与假设结果的窗口要从保存日的下一个交易日算到最终 `valid_until`，不能漏掉中间的交易日 → Task 2 `tests/test_retrospect.py::test_window_spans_from_first_validity_to_last_valid_until`。

3. 简报会话里 agent 对研究复看给 `watch` 且带新条件：被拒 `condition_needs_user`，原条件与有效期不变 → Task 3 `tests/test_v3_tools_research.py::test_brief_mode_watch_with_new_condition_is_rejected`。
4. 3 份规则计划满员、同一天已替换过一次，此时研究计划保存：照常成功、不记 `replaced`、名额仍是 0 → Task 3 `tests/test_v3_tools_plan.py::test_research_plan_ignores_slots_and_replacement`。
