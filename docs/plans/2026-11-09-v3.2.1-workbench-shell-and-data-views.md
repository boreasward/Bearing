# v3.2.1：工作台的壳、「纸面」视觉与数据视图 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 v3.2.1：对话居中的三栏工作台（左栏快捷入口 / 对话分段切换与折叠、右侧三面板抽屉）、「纸面」视觉令牌、覆盖 35 个工具的数据视图注册表与对话出卡（含历史回放）、七个完整视图、四个新读接口与工具调用结果落库。v3.2 的业务逻辑不动。

**Architecture:** 后端三步：**迁移 036 与仓储**（`v3_tool_calls.result` / `truncated`、对话列表的 `last_message_at`、运行与流水的读查询、配置四键、`core/schedule.py` 的下次运行推算）→ **运行时与工具面**（`runtime/pi.py` 从工具返回文本解析 `call:N` 并去掉 `mcp__ia__` 前缀、`dispatch._finish` 把结果落库并按阈值截断、`runtime/chat.py` 写标题 / 刷新活动时间 / 首帧 `start`、`get_market` 追加 `calc_version`）→ **页面接口**（`/api/market` 含 `watch[]`、`/api/runs`、`/api/ledger`、`/api/chats/{id}/calls`、`/api/today.counts`、消息行的 `agent_session`、对话列表的 `last_message_at`）。前端三步并行推进：**壳**（令牌、字体、三档圆角、路由、store、左栏 / 顶栏 / 抽屉外壳、窄屏 Sheet）、**视图**（注册表、十一种卡片、三个抽屉面板、三个新视图）、**对话**（回合块、工具卡、上下文芯片、快捷提问、历史回放）；最后组装与收尾。数据改动只有迁移 036 的两列。

**Tech Stack:** Python 3.11 / FastAPI / psycopg / PostgreSQL；Svelte 5（runes）+ bits-ui + Tailwind 4（`web/src/lib/ui` 现有组件层）；pytest（离线 + 一次性库 55433）、vitest + @testing-library/svelte。不新增 Python 依赖、不新增前端依赖（衬线字体用系统字体栈，图标仍是 `@lucide/svelte`）。

**Spec:** `docs/specs/2026-11-09-v3.2.1-workbench-shell-and-data-views-design.md`（下文「spec §x」），它在 v3.2 spec 与 `docs/design-system.md` 之上；冲突以 spec §17 为准。

## Review Focus

1. Pi 的 `tool_execution_end` 的 `result.content` 为空、或第一段不是 JSON、或 JSON 里没有 `ref`：事件 `ref` 为空、不抛、后续事件照常 → Task 2 `tests/test_runtime_pi.py::test_tool_end_without_parsable_ref_leaves_it_empty`。
2. 工具返回不可 JSON 序列化或超过阈值：`_finish` 仍返回正确信封给 agent，库里是截断记录，`result_sha256` 不变 → Task 2 `tests/test_v3_tools_dispatch.py::test_oversized_result_is_truncated_in_db_but_returned_whole`。
3. `/api/chats/{id}/calls` 被拿别的对话的 `agent_session` 调用：404 `unknown_call`，不泄露 → Task 3 `tests/test_api_chat.py::test_calls_endpoint_rejects_foreign_agent_session`。
4. 没有运行记录（空库）：`/api/market` 404 `no_run`，`/api/runs` 返回空 `runs` 与完整 `schedule`，`/api/today.counts` 全 0，页面顶栏写「还没有运行记录」、抽屉三面板 `empty` 态 → Task 3 `tests/test_api_runs.py::test_empty_database_gives_schedule_and_no_runs`、Task 6 `web/src/routes/Home.test.ts::no_run_state_renders_empty_panes`。
5. 对话里一轮调用了同一个工具两次：两张占位卡各自换成各自的 `call:N`，不串 → Task 6 `web/src/lib/chat/ChatPanel.test.ts::two_calls_of_the_same_tool_resolve_separately`。
6. 用户消息本身以 `[` 开头但不是芯片格式（如 `[1] 第一条`）：不被识别成芯片，原样显示 → Task 6 `web/src/lib/chat/context.test.ts::non_chip_brackets_are_left_alone`。
