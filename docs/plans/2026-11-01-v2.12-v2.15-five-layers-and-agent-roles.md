# v2.12–v2.15 合并实施 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `investment_assistant/` 按五层重组，并在新结构上一次交付 v2.12 数据层注册表、v2.13 公司研究员与研究档案、v2.14 组合经理、v2.15 系统内 roadmap 与优化提案，四个功能开关默认全开，发布 `v2.15.0`。

**Architecture:** 先纯搬家（`core ← data ← derivation ← execution ← analysis ← review ← optimize ← workflow / views ← api / services / tasks / notify`，守护测试锁住方向，口径数值用快照对照证明不变），再做一次迁移 031，然后按「纯函数 → 编排与 API → 前端 / 文档」三层加功能。`daily` 图升 `daily-3` / `stages-6`（13 节点：新增 `portfolio`、`propose`），Agent 子图运行版本 `agent-4`（计划 schema 仍 `agent-3`）。

**Tech Stack:** Python 3 / FastAPI / psycopg / LangGraph（PostgresSaver）/ PyYAML；Svelte 5 + Tailwind v4 + Vitest；PostgreSQL（迁移 SQL 手工执行）；pytest（离线 + 一次性库 55433）。

**Spec:** `docs/specs/2026-11-01-v2.12-v2.15-five-layers-and-agent-roles-design.md`（下文「spec §x」）。

1. Stooq 返回的行日期晚于最近已收盘交易日、或 `low ≤ open/close ≤ high` 不成立时，不得落库，目标按 `parse` 失败记 → Task 3 `test_data_sources_stooq.py::test_rejects_future_date_and_bad_ohlc`。
