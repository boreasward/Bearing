## 是什么

计划写下的价位只在短期内可信，有效期规定可以在哪几个交易日里按这份计划入场。v3.1 起有效期是 5 个交易日（配置 `v3.valid_sessions`，缺省 5），且计划跨天存续：到期只是这一条线的终态之一，见[计划状态](plan.status.md)。

## 怎么算 / 从哪来

- 有效期从保存（或延续）那天 T 之后的第 1 个交易日（T+1）到第 5 个交易日（T+5），按美股交易日历数，周末和休市日不算。计划记 `valid_from` 与 `valid_until`。
- **延续重新起算**：有待入场计划的股票再次上榜且 agent 确认后「延续」，数字不变，有效期从当天重新起算（新的 T+1 至 T+5），股数按当天总资产重算；「修订」只改价位 / 论点 / 最长持有，不重算有效期。
- **到期**：复查交易日已到或超过 `valid_until` 还没买入，计划记 `expired`，原因写实际交易日数（如「5 个交易日未买入」）。
- 有效期内有财报，计划整份作废，见[财报规则](plan.earnings.md)。
- 每天的到期与财报判定由宿主的待入场复查完成；当天缺日线时跳过「跌破止损」判定，其余照常。

## 在系统里哪里看到

- 页面「计划与持仓」的待入场卡片（有效至）；简报的「待入场计划」每份一行（第几天、有效至）。
- 对话里 `get_plans` 读到的 `valid_from` / `valid_until`；变化记录里的「延续」「过期」行。

## 注意

- 与 v2 的口径（T+1 至 T+3、每天覆盖保存）不同：v3.1 一只股票一份计划，有效期只在延续时重算，不存在「每天一份新计划」。
- 规则**未经验证**。
