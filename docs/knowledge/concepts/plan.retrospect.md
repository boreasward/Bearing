## 是什么
复盘回答两个问题：「我执行得怎么样」（每份已结束的计划一行）与「规则行不行」（分组统计）。它不另建记录表：每次都从 `v3_plans`、`v3_plan_events`、`v3_trades`、`v3_candidates`、日线现算，页面打开时算，周报由每日任务用同一个函数算出来写进简报行。

复盘对象是五个终态（`closed` / `expired` / `invalidated` / `replaced` / `cancelled`）各一份一行；补录计划进复盘但只算结果、不打偏差标签，R 倍数写「补录，不计」。

## 怎么算 / 从哪来
- **偏差标签**八个代码，全部由宿主按记录算：`not_bought_in_zone`（待入场过期且有效期窗口内有日线进过入场区间）、`entry_out_of_zone`（买价出区间）、`over_bought`（多买）、`stop_order_missing`（止损未挂）、`late_sell_after_stop` / `late_sell_after_instruction`（晚卖 N 个交易日）、`early_sell`（早卖）。价格从未进入场区间而没买记 `not_filled`——**不算偏差**，算「照做」。被替换、被取消、agent 否决作废的计划不打 `not_bought_in_zone`（结束不是用户的决定），只在假设结果里看。
- **R 倍数** = (离场价 − 入场价) / (入场价 − 初始止损)。初始[止损](plan.stop.md)取计划行的 `initial_stop`：待入场阶段修订止损时宿主会同步改它，保证分母用的是「买入前定的止损」。
- **假设结果**（没买的计划）：用计划行的价位和之后的日线模拟——窗口内某天 `low ≤ 入场上沿` 则成交，成交价 = `min(开盘, 入场上沿)`；没成交但收盘跌破止损 → 「未成交：收盘跌破止损」；窗口走完没成交 → 「未成交：价格未进入场区间」；成交后用计划线现有的持仓检查逐日推（`stop_hit` 当天按 `min(开盘, 生效止损)` 离场，`sell_instruction` 次日开盘离场）；日线用完还没离场 → 「进行中」。替换与取消不影响模拟。有效期窗口从保存日的下一个交易日到最终 `valid_until`（中间被延续过也不漏交易日）。
- **规则检验**：按触发规则、形态档位、行业组三个键各分一次组，每组给样本数、胜率、平均 R、R 合计；真实成交与假设结果**两张表、互不相加**。样本数低于 `v3.retro_min_sample`（缺省 10）的组只显示样本数与「样本不足」，不给胜率与平均 R。
- **周报**：每周最后一个交易日（当天的下一个交易日落在另一个 ISO 周）的每日任务在最终简报之后算本周汇总，写进简报行的 `weekly_md` 并单独推一条 Discord（同一周重跑不重推）；没选定模型的日子照常产出并推送（周报全是宿主算的），事实任务失败的日子不产出、下次也不补。

## 在系统里哪里看到
页面「复盘」块：顶部本周汇总（可切换以前的周）、中间执行复盘表（缺省最近 20 份、可翻）、底部规则检验两张表；没有已结束的计划时整块显示「还没有已结束的计划」。周报正文在当天的简报行里。

## 注意
- 复盘只给数，不改规则：按复盘结果调筛选规则是另一版的事；规则**未经验证**，样本不足的组宁可不给数。
- 假设结果与真实成交在任何一张表或一个数里都不混。
