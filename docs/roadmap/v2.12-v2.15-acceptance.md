### Stooq 日线 CSV：不可用

- 请求 `https://stooq.com/q/d/l/?s=<t>.us&i=d`（AAPL、MSFT、NVDA、SPY、QQQ）：**五只全部 HTTP 404**（响应体 271 字节 HTML）。
- 响应体内容为 Stooq 官方 404 页：「The page you requested does not exist or has been moved」，即该 CSV 端点已下线或迁移，不是代码格式问题。
- 诊断变体同样 404：`?s=spy&i=d`（去掉 `.us` 后缀）、`https://stooq.com/q/l/?s=spy.us&i=d`。
- 列名、最近 3 行、「最近日期 = `last_completed_trading_day()`（2026-10-30）」比对：**无数据可比**。
- **NVDA 拆股调整判断（2024-06-10 十比一拆股，看 2024-06-07 收盘是否 ≈121.8 而非 ≈1218）：无数据，无法验证**；源本身不可用后该问题不再有决策意义。
- 结论：**Stooq 备源不可用**。按 spec §21 Q3，Task 3 的 `data/sources/stooq.py` 不再实现，`sources` 只留主源。

### Nasdaq JSON API：可用（财报日备源）

带浏览器 `User-Agent` 与 `Accept: application/json` 请求：

- `https://api.nasdaq.com/api/analyst/<t>/earnings-date`（AAPL、MSFT、NVDA、SPY、QQQ）：全部 **HTTP 200，`application/json`**。
  - 顶层字段：`data`、`message`、`status`；`data` 内字段：`announcement`、`eQRResposeModel`、`heading`、`reportText`。
  - 财报日在 `data.announcement` 文本里，例如 NVDA：`"Earnings announcement* for NVDA: Nov 17, 2026"`（需文本解析日期）；`eQRResposeModel` 本例全空。
  - ETF（SPY、QQQ）`data` 为 `null`，符合预期（ETF 无财报日），调用方需把 `data == null` 当「无数据」处理。
- `https://api.nasdaq.com/api/calendar/earnings?date=<今天>`：**HTTP 200，`application/json`**；`data` 内字段：`asOf`、`headers`、`rows`。
  - 交易日（2026-10-30）返回 66 行，行字段：`symbol`、`name`、`eps`、`surprise`、`time`、`marketCap`、`fiscalQuarterEnding`、`epsForecast`、`noOfEsts`（金额带 `$` 与千分位，需解析）。
  - 非交易日（2026-11-01，周日）返回 0 行，行为正确。
  - 注意：`time` 常为 `"time-not-supplied"`，盘前/盘后时点不可依赖；系统需要的是财报日期，日期本身可用。
- 结论：**Nasdaq 备源可用**（analyst 查单标的财报日期 + calendar 按日历拉全市场），Task 3 的 `data/sources/nasdaq.py` 照此形状实现。
